# DOKI DOKI MODELO CLUB — site

Abra `index.html` no navegador.

- `index.html`: textos, seções, personagens e links.
- `style.css`: cores, fontes, tamanhos e layout.
- `script.js`: efeitos/interações.
- `assets/`: coloque imagens do seu mod aqui.

Para trocar uma imagem, por exemplo:
`<img src="assets/monika.png" alt="Personagem">`

Os botões de download estão como `href="#"`; substitua pelos links/arquivos reais.
